# Sudoku Party
<img width="800" height="420" alt="Screenshot 2026-10-05 at 12 36 24" src="https://github.com/user-attachments/assets/85726d03-9ab2-4433-bd8d-6b01acd3455b" />

A multiplayer Sudoku game built with React and WebSockets.

Players can solve standard 9x9 Sudoku puzzles. Multiplayer support enables players to join a shared game and receive puzzle updates in real time.

## Tech Stack
- React
- TypeScript
- Chakra UI
- WebSockets
- Node.js

## Development
Install dependencies and start the frontend:

```bash
cd frontend
npm install
npm run dev
```

Start the WebSocket server:

```bash
cd websocket
npm install
npm run dev
```

## Status
Currently building out real-time multiplayer functionality.
